# Create: Media Systems

様々なメディアをゲーム内で再生可能にするNeoforge向けMod

## 対応環境

- Minecraft 1.21.1 / NeoForge 21.1
- Create 6.0.10^
- Java 21

Modの完全な動作には、[CMS-API](https://github.com/haruyq/CMS-API)が別途必要です。  

## ビルド

```bash
./gradlew build
```

## 音ブロック

銅ブロックの上に置いた音ブロックで、Minecraft 26.1のトランペット音を使えます。銅ブロック・切り込み入りの銅・模様入りの銅・切り込み入りの銅の階段とハーフブロックに対応し、酸化の4段階で音色が変わります。錆止め済みの銅でも同じ音色を保てます。音程の変更、レッドストーンでの演奏、上に置いたモブの頭の音は通常どおりです。

ビルド時にMojangの公式配信元から音源を取得し、ハッシュを検証してJARへ同梱します。音源の権利はMojangに帰属し、このリポジトリのMITライセンスの対象外です。

## ミニコンポ

アンプ、サウンドコントローラー、チューナー、ディスクプレーヤー、ダブルカセットデッキを、1ブロックの中に積んで組むオーディオシステムです。CD・DVD・Blu-ray・カスタムディスク・カセットテープを再生し、専用スピーカーから左右に分けて鳴らします。機器どうしとスピーカーは、背面でオーディオケーブルを使ってつなぎます。

前面のボタンとつまみは、狙って右クリックで操作します。組み方とつなぎ方は、ゲーム内で各機器のアイテムの「思案」から確認できます。
